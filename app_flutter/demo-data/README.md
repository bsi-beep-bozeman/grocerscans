# Twenty-product demo catalog

[Download the CSV](catalog-20.csv). Import UPC-A/EAN-13 columns as text to preserve leading zeroes.

All 20 primary UPC-A identifiers are synthetic and have valid check digits. They are not verified manufacturer assignments and should be used only with this demo. The product/pack names, quantities and days remaining are fictional scenarios, not handling rules or shelf-life recommendations.

The local Flutter preview uses the same records; enter any listed SKU or UPC-A, or its zero-prefixed EAN-13 equivalent. The original five illustrative barcode values remain lookup aliases for compatibility with earlier walkthroughs. Four of those legacy identifiers fail the check-digit calculation, so use the new primary values for barcode exercises.

Saving a preview batch creates session activity only. The hosted demo remains its previous five-product snapshot until a separately approved rebuild/publication. No real catalog or inventory has been imported.
