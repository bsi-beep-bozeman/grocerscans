# Try ShelfLife in ten minutes

This is a fictional practice store. Each browser keeps its own work. Use sample information only. The public PINs below simulate staff roles; they are not secure accounts.

1. Open **Admin setup**. Market Street is selected. Change the store name and choose **Save draft**. Explore the six setup steps.
2. Open **Review & activate**, choose **Review activation**, enter a reason and activate the configuration.
3. Return to the demo and open **Staff receiving**. Enter Alex's practice PIN **2468**.
4. Search for **milk**, select **Whole milk**, and enter quantity **6**. Put a fictional delivery reference and printed expiry date in **Notes**. Dedicated expiry entry is not built yet.
5. Choose **Save on this device** and wait for the saved message. Refresh, enter 2468 again and use **Open a saved draft** to reopen it.
6. Choose **Lock**, then enter Sam's PIN **1357**. Alex's drafts should not appear. Lock and return with 2468 to see them again.
7. Return to the welcome page. **Reset practice data** lets you repeat the exercise; cancelling preserves your work.

Use one tab at a time. Your client can perform the same exercise independently in their browser once the remote URL is published. There is currently no cross-device/shared store data. Clearing browser site data removes practice work.

Please record the step, expected result, actual result, device/browser and a screenshot for anything confusing. What feels clear? What slows down a shift? What is missing?

Saving a draft does not receive stock or submit a receipt. This preview does not test real authentication, live inventory, camera scanning, automatic expiry calculations or operational rollout.
